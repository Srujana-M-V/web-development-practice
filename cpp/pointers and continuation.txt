STRUCTURE ,UNION;

Think of a union as a single room where only one person can stay at a time.
💡 Think of a structure as a house with multiple rooms, where many people can stay at once. When you only need one value at a time (e.g., either an integer or a float).
✅ When you want to save memory (especially useful in embedded systems and microcontrollers).

STRUCT
In a struct, rollNumber (4 bytes) and marks (4 bytes) each have their own space → Total 8 bytes
In a union, rollNumber and marks share the same space → Only 4 bytes (max size of one member)

ENUM
An enum (enumeration) is a user-defined data type that allows you to assign names to a set of integer values.
Why Use Enums?
Instead of using random numbers, we can use meaningful names.
It makes the code more readable and easier to understand.
It prevents using invalid values by restricting them to a predefined list.

typedef in Structure in C++
The typedef keyword in C++ is used to give a new name (alias) to an existing data type, including structures. This makes code more readable and easier to use.

🔹 Syntax of typedef with struct
cpp
Copy
Edit
#include <iostream>
using namespace std;

// Define a structure and give it an alias using typedef
typedef struct Laptop {
    string brand;
    int ram;
    float price;
} Lap;  // "Lap" is an alias for "struct Laptop"

int main() {
    // Now we can use "Lap" instead of "struct Laptop"
    Lap l1;
    
    l1.brand = "Dell";
    l1.ram = 16;
    l1.price = 75000.50;

    cout << "Brand: " << l1.brand << endl;
    cout << "RAM: " << l1.ram << " GB" << endl;
    cout << "Price: Rs. " << l1.price << endl;

    return 0;
}

enum is used for defining named constants.
By default, values start from 0 and increase by 1, but you can assign custom values.
Enums are useful in switch cases, condition checking, and improving code clarity.
Unlike struct or union, enum is not used for storing data but for defining fixed sets of values.

#include <iostream>
using namespace std;

enum TrafficLight { RED, YELLOW, GREEN };

int main() {
    TrafficLight signal = RED;

    switch (signal) {
        case RED:
            cout << "STOP!" << endl;
            break;
        case YELLOW:
            cout << "GET READY!" << endl;
            break;
        case GREEN:
            cout << "GO!" << endl;
            break;
        default:
            cout << "Invalid signal!" << endl;
    }
    return 0;
}
